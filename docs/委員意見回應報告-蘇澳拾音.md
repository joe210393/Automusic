## 10. AI 詞曲生成輔助平台：實際完成範圍

### 10.1 是否為自有地端平台？

**是：自有產品與編排管線，非僅「代操作」商業音樂 App。**

| 層級 | 說明 |
|------|------|
| **自有** | 遊客旅程 UI、旅程狀態機、蘇澳內容包 CMS、帳號／額度／TOKEN、管理後台、分享頁、聲音→旋律分析與可解釋對照 |
| **自有部署管線** | FastAPI 服務；本機引擎（ACE-Step、LM Studio、FluidSynth 等）經地端執行；雲端（Zeabur）可經安全通道呼叫本機引擎 |
| **非自訓大模型** | 詞曲／演唱推論使用開源或可本機部署之模型／引擎（見第 13 點授權）；**不是**以官方帳號代客操作 Suno／Udio 等封閉 SaaS 為主路徑 |

**一句話定位：**  
「自有觀光體驗與內容營運平台」＋「本機可部署之開源／開源權重音樂生成引擎」；不是純串接既有線上 AI 工具的操作手冊。

### 10.2 功能完成對照（委員列舉項目）

| 功能 | 完成狀態 | 說明 |
|------|----------|------|
| 現場上傳（旅行聲音） | **已完成** | 依路線任務卡現場錄音並上傳至該趟旅程 |

## 11.「一地一資料庫」具體化：蘇澳示範格式

### 11.1 原則

「一地一資料庫」＝**一個目的地一個可版本化的內容包**（現行以 JSON 內容庫實作，可匯出／複製到下一站）。  
蘇澳為示範站；複製到他縣市時替換內容欄位，保留同一套旅程引擎。

### 11.2 現行已落地欄位（系統實作）

```text
destination/
  id, enabled, contentRevision
  brand/          地名、主標、副標、CTA、核心句、示範歌
  routes[]/       路線 id、名稱、導覽句
    soundTasks[]/ 任務卡：聲音槽位 id、標籤（現場要錄什麼）
  moodStyles[]/   感覺卡：觀光語意 → 引擎樂風（含「今日驚喜」隨機）
  storyPrompts/   地方／同行／情緒提示、回憶填寫引導
```

蘇澳示範路線（節錄）：冷泉篇、南方澳漁港篇、海岸篇、市場篇、老街篇、親子篇；各含 3 個聲音任務卡。

### 11.3 期末建議完整「蘇澳示範資料庫」格式（可複製欄位）

下列格式將現行內容包**擴充為委員要求之完整模組**（部分欄位為期末應補齊之內容／營運欄位；結構已對齊可匯入 CMS）：

#### A. 地方聲音素材（Sound Assets）

| 欄位 | 類型 | 說明 | 可替換 |
|------|------|------|--------|
| `asset_id` | string | 素材唯一碼 | ✓ |
| `route_id` / `task_id` | string | 對應路線與任務卡 | ✓ |
| `label` | string | 如「冷泉流水」 | ✓ |
| `source_type` | enum | `field_recording` / `licensed_stock` / `user_trip` | ✓ |
| `file_ref` | string | 路徑或物件鍵 | ✓ |
| `capture_place` | string | 錄製地點敘述 | ✓ |
| `rights` | object | 授權類型、期限、出處 | ✓ |
| `usage` | enum | `melody_material_only` / `preview_bed` / `archive` | ✓ |

> 遊客當場錄音歸屬「該趟旅程 user_trip」；地方示範庫可另備授權過的環境參考檔供教學演示。

#### B. 文化關鍵字（Culture Keywords）

| 欄位 | 說明 | 可替換 |
|------|------|--------|
| `keyword` | 如「南方澳」「鯖魚」「冷泉」 | ✓ |
| `category` | place / food / festival / feeling / person | ✓ |
| `route_ids[]` | 建議出現於哪些路線 | ✓ |
| `lyric_hint` | 作詞提示（非強制寫入歌詞） | ✓ |
| `sensitive` | 是否避開商業品牌／個資 | ✓ |

#### C. 故事腳本（Story Scripts）

| 欄位 | 說明 | 可替換 |
|------|------|--------|
| `script_id` | 腳本碼 | ✓ |
| `route_id` | 所屬路線 | ✓ |
| `beats[]` | 開場／收集／創作／帶走 各段口白與時間盒 | ✓ |
| `educator_note` | 講師引導重點 | ✓ |
| `child_safe_variant` | 親子場次改寫 | ✓ |

#### D. 任務卡（Mission / Sound Tasks）— 已實作核心

| 欄位 | 說明 |
|------|------|
| `id`, `label` | 任務識別與顯示名稱 |
| `blurb`（建議補） | 為何要錄、錄多久、安全提醒 |
| `min_seconds` / `max_seconds`（建議補） | 錄音長度規範 |
| `success_criteria`（建議補） | 例如「至少成功上傳 2／3 槽」 |

#### E. 歌詞模板（Lyric Templates）

| 欄位 | 說明 | 可替換 |
|------|------|--------|
| `template_id` | 模板碼 | ✓ |
| `mood_or_style` | 對應感覺卡／樂風 | ✓ |
| `structure` | `[Intro][Verse][Chorus]…` | ✓ |
| `slot_rules` | 地名、同行、回憶如何填入 | ✓ |
| `fallback_lines` | LM 失敗時模板句 | ✓ |
| `language` | 預設 `zh-Hant` | ✓ |

#### F. 授權紀錄（Rights & Consent Log）

| 欄位 | 說明 |
|------|------|
| `record_id`, `at` | 紀錄與時間（台灣時區） |
| `subject` | `destination_asset` / `user_voice` / `generated_work` |
| `journey_id` / `account_id` | 關聯 |
| `consent_type` | 聲紋同意、作品分享同意、行銷素材同意等 |
| `scope` | 保存範圍、可否公開、可否商業使用 |
| `retention_until` / `delete_requested_at` | 保存與刪除請求 |
| `license_spdx_or_name` | 模型／素材授權名稱 |

#### G. 可替換欄位總表（換下一站時優先替換）

`brand.*`、`routes[]`、`soundTasks[]`、`moodStyles[]`、`storyPrompts`、文化關鍵字表、故事腳本、歌詞模板、地方授權素材清單、場域安全注意事項。

**引擎與帳號／TOKEN 邏輯不需重寫** → 可複製性落在資料與腳本，而非口頭概念。

### 11.4 在地辨識度如何被「聽見／看見」

- 路線與任務卡使用蘇澳真實場景語彙（冷泉、漁港、老街等）。  
- 成品頁／創作頁呈現「你收集的聲音 → 調性／速度／輪廓／動機如何寫進歌」（說明原音不直接吵雜疊軌，而是推導音樂參數）。  
- 品牌文案與核心句服務「把旅行帶回家」，而非通用 AI 作曲工具介面。

| 穩定性 | 健康檢查、本機引擎守護、雲端經安全通道呼叫；用量與錯誤 log | 已有基礎 |
| 維運 | 指定系統操作人力；異常重試與場次備援流程（改時段／縮短波次） | 執行期演練 |

### 風險二：兒童聲音、AI 演唱、個資與人格權

| 項目 | 控管作法 | 狀態 |
|------|----------|------|
| 家長同意 | 聲紋／兒童參與書面或數位同意；不同意仍可僅用 AI 歌手版 | UI 同意已有；紙本／親子加強版建議補 |
| 最小必要 | 僅錄製製作所需短句；不作無關蒐集 | 已朝此設計 |
| 保存期限 | 明訂旅程／聲紋保存天數；到期刪除或依請求刪除 | **須補正式保存與刪除機制（技術＋公告）** |
| 人格權 | 禁止未經同意將兒童聲音用於廣宣；行銷素材另徵同意 | 契約與場次 SOP |

### 風險三：委外技術 vs 申請單位內部成果

| 歸屬 | 內容 |
|------|------|
| **委外／技術開發成果** | Automusic 平台、引擎串接、後台、部署與維運文件 |
| **申請單位內部成果（文化轉譯與驗證）** | 蘇澳故事腳本、任務卡文案、教學設計、顧客旅程、場域動線、試辦與付費驗證、通路關係、在地辨識內容編輯 |
| **交接** | 內容包編輯權在申請單位／場域；技術文件與帳號權限分級 |

審查時以「內容與場域驗證由申請單位主導、系統為承載模組」表述，避免成果全部計入委外。
